# Library candidates

A helper written inline in a day's `solution.ts` is logged here at wrap-up, one line each: the day, the helper and what it does. When a second day needs the same helper, move it into the right module in `src/lib` with a test and TSDoc, add it to the exports list in `CLAUDE.md`, and delete its line here.

Format: `- dayNN: helperName, what it does`
